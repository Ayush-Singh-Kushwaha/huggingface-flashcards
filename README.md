# Hugging Face Flashcards

A Python-based flashcard generator using the Hugging Face Inference API.

## Features

- Takes a topic from the user
- Generates 5 study flashcards
- Uses Hugging Face InferenceClient
- Keeps the Hugging Face API token in an environment variable
